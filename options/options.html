How to add your API key
  1. In the extension's folder (the one with manifest.json), copy .env.example to a new file named .env.
  2. Put your key in it: ANTHROPIC_API_KEY=sk-ant-…
  3. At chrome://extensions, click the reload icon on Job Autofill, then reopen this page.

.env is git-ignored and only this extension can read it. Web pages can't.
